YOMU NOTE v0.7.1a — READING PROGRESS HOTFIX (SOURCE CANDIDATE)
================================================================
Based directly on the user-supplied v0.7.1 source ZIP. No unrelated feature
changes are included.

CRASH FIX
---------
v0.7.1 added a QLabel and QProgressBar to the default QMainWindow status
bar, then called setStatusBar(QStatusBar()) a second time. Replacing Qt's
status bar destroyed the old bar and its child widgets. Their Python
references remained, causing the repeated "libshiboken: QLabel already
deleted" exception on read-checkbox changes and a "Could not add tab"
dialog. v0.7.1a creates the bar ONCE before inserting the permanent widgets.
There is no silent try/except or disabled progress counter.

CHECKBOX APPEARANCE
-------------------
Only the read-status checkboxes in the Groups tree are repainted. Unread is
softly tinted with the palette accent; read uses the accent with a contrasting
check mark; partly read uses the accent with a dash. The same drawing path
uses QPalette's paper colour and the existing group-tree accent colour for
all Yomu themes, light and dark, including System mode. Native Qt checkbox
hit regions, page/group IDs, selection, reading-history callbacks, drag/drop,
progress arithmetic and thumbnails remain unchanged.

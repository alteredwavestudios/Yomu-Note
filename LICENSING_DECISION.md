### Optional per-file SPDX header for first-party Python source

```python

```

Only add this header to code you own or have permission to relicense.
For original third-party code keep its existing header and actual licence.

### Before public publishing

- Confirm contributors/rights owners have agreed to GPL-3.0-or-later.
- Set an appropriate copyright notice naming the correct rights holder(s)
  in the README / project metadata if you want one shown prominently.
- Decide how you want to licence original icons and jingles (or confirm GPL
  permission), and review every screenshot for third-party textbook content.
- Do not distribute unverified installer binaries without their full notices.
